# Erratum to amendment v0.7 (ActionSense): seeds 300–304 were used before

**Status:** Proposed — awaiting PI sign-off.
**Date:** 2026-10-31
**Applies to:** `docs/osf/amendment-v0.7-actionsense.md`, frozen at tag
`bouba_sens/v0.7-actionsense-prereg` (commit `02c2407`,
`swh:1:rev:02c24073d3a04e1db3d3adf2ee77e545c0bdde17`). The frozen text is
not edited. No seed, cell, threshold or rule of v0.7 changes.

## Fact

The amendment says twice that the confirmatory seeds 300–304 were
"never used in the repository":

- §4.1, line 335: "Confirmatory seeds **300, 301, 302, 303, 304** (never
  used in the repository)";
- §8, item 3, line 517: "Confirmatory ActionSense seeds: **300-304**
  (never used in the repository; …)".

This is wrong. The B-3 lesion × query interaction study of 2026-10-27
(`docs/prereg/2026-10-26-b3-lesion-interaction.md` §6, results in
`docs/milestones/2026-10-27-b3-lesion-interaction-results.md`) ran its
confirmatory grid on seeds **300–309**, Gaussian world,
`EMISSION=straight-through scripts/run_grid_probe_v2.sh`, three days
before the v0.7 freeze.

## Corrected statement

Seeds 300–304 had been used once, by the 2026-10-27 Gaussian grid. They
had never been used on the ActionSense world, and no ActionSense grid
has run with any seed.

## Consequences

- **No data overlap.** The 2026-10-27 grid used the synthetic Gaussian
  world. v0.7 uses the real ActionSense recordings (S00, S02–S05). No
  ActionSense datum was seen through those seeds.
- **Shared seed values.** Both scripts derive the phase-1 seed (`seed`),
  the lesion seed (`seed * 10000 + count`) and the trio probe seeds
  (`seed * 10000 + 5000 + trio`, `seed * 10000 + 5099`) with the same
  rules. Random streams that do not depend on the world (for instance
  parameter initialisation, if the network shapes match) can therefore
  coincide between the two studies. v0.7 never treats its results as
  independent of the 2026-10-27 results, and it pools nothing across
  worlds, so no test of v0.7 relies on that independence.
- **Seeds kept.** The seeds stay 300–304 as frozen. Changing them now
  would be a protocol change, while this note only corrects a factual
  claim.
- **Seed checks in later preregistrations** must search the run
  records (`SEEDS` lists in prereg and milestone files), not only the
  scripts, before calling a seed unused.
