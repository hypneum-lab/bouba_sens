## 2. Probe (ADR-0023)

For a model and a probe seed s: held-out test items
`world.sample(256, seed=s)`, training pool `world.sample(512, seed=s+1)`
minus items whose raw inputs equal a test item's. For each query
modality q: frozen 128-d pre-argmax hidden state of q's sensory pathway
on q's clean input only; standardisation + multinomial logistic
regression, C ∈ {0.01, 0.1, 1, 10} by 5-fold shuffled CV on the pool
(fold seed 0, ties → smallest C), refit on the pool, per-item 0/1 on the
test items (`AdaptationLoop.probe_v2`). Baseline = training-pool
majority class scored on the test items.

`P[q, m]` = held-out accuracy of the v2 probe on q for the model lesioned
on m (after Phase 2), from `per_query_successes_v2.json`. The five cells
of a (seed, timing, SNR) trio share the probe seed
`seed · 10000 + 5000 + trio` (`trio = 3·timing_index + snr_index`), so
`P[q, m]` and `P[m, q]` are scored on the same 256 world items.

## 3. Positive control (precondition)

On each world separately: the intact network of each confirmatory seed
(Phase-1 checkpoint, before any lesion), probed with seed
`seed · 10000 + 5099`. Control modality fixed a priori: **vision** (both
worlds). Margin = accuracy − baseline. **The control passes if the mean
margin over the five confirmatory seeds is ≥ 0.10.** The untrained
reference (`init_*` files) is reported, descriptive only.

## 4. Hypothesis, statistic, null

- **H0** (per world): symmetry of the expected performances,
  `E[P[q, m]] = E[P[m, q]]` for every pair q ≠ m.
- **Statistic:** for each of the 30 trios, `Me6_v2 = max_{q≠m}
  |P[q, m] − P[m, q]|`; the B-3 v2 statistic is the **median over the 30
  trios**.
- **Null:** paired sign flip of the per-item differences
  `d_i = s_qm(i) − s_mq(i)` (`scripts/me6_paired_null.py
  --successes-file per_query_successes_v2.json`), independent signs per
  (trio, pair, block of b consecutive items), B = 20 000 replicates,
  seed 25102026. One-sided p = (#{null median ≥ observed} + 1) / (B + 1).
- **Block length b** — rule fixed here, applied to a separate pilot grid
  (§5), independent of the confirmatory result:
  - iid-sampled worlds (Gaussian): **b = 1** by design (the pilot ACF is
    reported only);
  - contiguous-window worlds (mock): lag-k autocorrelation of the paired
    differences d_i of the v2 probe on the pilot grid — per series
    (trio × pair), centred on its own mean, mean over series with
    non-zero variance (ADR-0022 estimator) — for k = 1 … 64 (n / 4);
    k* = smallest k with ACF(k) < 0.1; **b = 1 if k* = 1, else the power
    of two ≥ k***; b = 64 if the ACF never falls below 0.1.
  - Implementation: `scripts/b3_probe_v2.py block`.

## 5. Runs

All on electron-server (8-core Xeon X5680, CPU torch), nice 19, four
cells at a time, `scripts/run_grid_probe_v2.sh` at the tagged commit,
`run_grid.sh` defaults (STEPS_TRAIN 200, STEPS_LESION 100, metrics
Me1,Me2,Me3, gating hard, τ 1.0, lesion seed `seed · 10000 + count`).
Worlds: `gaussian` and `studyforrest` without data cache (mock mode).

1. **Pilot** — seeds **100, 101** (2 × 30 cells per world, 12 trios). Only
   the block rule (and descriptive ACF / control) is computed; the
   result is committed in `docs/prereg/2026-10-25-b3-probe-v2-pilot.md`
   with `reports/b3_probe_v2_pilot_{gaussian,mock}.json` **before** the
   confirmatory grids start. No B-3 v2 statistic is computed on the
   pilot.
2. **Confirmatory** — seeds **200, 201, 202, 203, 204** (150 cells per
   world, 30 trios). Estimated cost ≈ 35–60 s per Gaussian cell and
   ≈ 160 s per mock cell, i.e. ≈ 0.5 h + ≈ 1.7 h at four in parallel.
   If the total estimate exceeds 10 h, only the Gaussian grid is run and
   the mock grid is reported as not done.
3. **Analysis** — `scripts/b3_probe_v2.py report --world W --block b`
   → `reports/b3_probe_v2_{gaussian,mock}.json`.

## 6. Decision rule (per world, applied in this order)

1. Positive control fails (mean vision margin < 0.10) → **non
   concluant** (« inconclusive: positive control failed »).
2. Fewer than 30 complete trios → **non concluant** (incomplete grid).
3. p < 0.01 → B-3 v2 **« asymétrie présente »**.
4. p ≥ 0.05 → B-3 v2 **« compatible avec le nul »**.
5. 0.01 ≤ p < 0.05 → **non concluant**.

The two worlds are read separately (no pooling, no multiplicity
adjustment across the two worlds; unadjusted p values are reported).
The locked 0.02 threshold of B-3 (v1) is neither used nor changed.

## 7. Exploratory (not confirmatory) outputs

Per-trio and per-pair rows of the null, the v1 zero-masking statistic on
the new grids, the code-channel collapse diagnostics, the untrained
reference, any other block length, and anything on the PR #40 grids.

## 8. Interpretation limits (declared now)

B-3 v2 tests asymmetry of linear decodability from each modality's own
representation, not transfer through the nerve (the code channel is
collapsed in these networks, ADR-0023). A rejection of H0 says nothing
about the 3+2 perceptive / proprioceptive partition (ADR-0014).
